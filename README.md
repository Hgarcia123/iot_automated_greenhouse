# Contexto do Projecto
Este é um projecto de Internet of Things (IoT) desenvolvido no âmbito de projeto final da Licenciatura em Engenharia Eletrotécnica e de Computadores. Este é na realidade uma junção de 

- Base de Dados (SQL)
- Eletrónica de Aquisição e Processamento de Sinais
- Programação de Microcontroladores
- Sistemas Embebidos
- Desenvolvimento Frontend e Backend de Websites

# Objectivos
O objetivo principal deste projeto é a automatização completa das necessidades que cada planta necessita para uma dada estufa, recorrendo a telemetria obtida através de sensores de humidade do solo, ar e luz. Com isto é possível definir lógica para o uso de atuadores como um motor de rega e ventoinha de forma a controlar as condições atmosféricas da estufa, sem necessidade de intervenção humana.
